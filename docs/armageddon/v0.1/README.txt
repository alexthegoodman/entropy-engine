ARMAGEDDON 2070 — DESIGN DATABASE v0.1

This archive contains one CSV per major game-design category.

IMPORTANT
- "Proposed" and "Concept" indicate design status, not finalized implementation.
- "TBD" means the value has deliberately not been decided yet.
- IDs are intended to remain stable when names or balance values change.
- Vehicle capacities and the 8-person squad structure reflect the current design brief.
- Hunter Protocol's 80% success rate is recorded as a proposed per-target neutralization probability; exact implementation and counterplay remain to be balanced.
- The Mine Kit's 16-mine payload is recorded from the current design brief.
